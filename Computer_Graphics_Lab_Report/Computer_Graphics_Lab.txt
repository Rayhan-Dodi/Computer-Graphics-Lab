\section{Introduction}

\subsection{What is Computer Graphics?}
Computer graphics is a sub-field of computer science that studies methods for digitally synthesizing and manipulating visual content. It encompasses the creation, storage, and manipulation of models and images of objects. Through computational algorithms, mathematical principles, and specialized hardware, computer graphics translates abstract programmatic and numerical concepts into human-readable visual formats on display devices. Key components include rendering (2D and 3D scenes), geometric transformations, rasterization, clipping, and shading.

\subsection{Importance of Computer Graphics}
The significance of computer graphics spans numerous industries and modern technologies. It is the foundational technology behind graphical user interfaces (GUIs), enabling intuitive interaction with software. In the medical field, it powers the visualization of complex data, such as rendering MRI and CT scans for diagnostics. Engineering and architecture rely heavily on Computer-Aided Design (CAD) for modeling and simulating physical structures. Furthermore, the entertainment industry---including video games, animation, and virtual reality---depends entirely on advanced rendering techniques to create immersive digital experiences.

\subsection{Objectives of the Laboratory Work}
These laboratory exercises are designed to provide practical implementation of foundational graphics algorithms and techniques. The primary objectives of this lab are:
\begin{itemize}
    \item To gain hands-on experience with foundational graphics APIs (such as the BGI library in C).
    \item To implement primitive drawing algorithms (line generation, circle generation) and understand their underlying mathematical logic (e.g., DDA, Bresenham's, Midpoint).
    \item To apply geometric transformations mathematically, including translation, rotation, scaling, and shearing.
    \item To implement and understand region-filling algorithms (Flood Fill, Boundary Fill) and connectivity concepts.
    \item To generate complex curves (Cubic B\'{e}zier) and implement double-buffered animations (page flipping) for dynamic scenes.
\end{itemize}

\section{Experiment 1: DDA and Bresenham's Line Drawing Algorithms}

\subsection{Objective}
To understand and implement the Digital Differential Analyzer (DDA) and Bresenham's Line Drawing Algorithms for rasterizing straight line segments on a digital screen.

\subsection{Theory/Background}
\textbf{DDA Algorithm:} DDA draws a line by incrementally stepping one pixel at a time along the dominant axis (the axis with the larger span). The other axis advances by a fractional increment each step, derived from the ratio $dy/dx$ or $dx/dy$. Rounding via $+0.5$ maps each floating-point position to the nearest pixel.

\textbf{Bresenham's Algorithm:} Bresenham's algorithm avoids floating-point arithmetic by maintaining an integer ``decision parameter'' ($d$) that tracks the cumulative error between the ideal line and the pixel grid. At each step along the dominant axis, $d$ determines whether the minor axis should advance or stay. It works with absolute deltas and derives unit step signs from the original direction, swapping axes for steep lines where $|dy| > |dx|$.

\subsection{Source Code}
\textbf{Experiment 1A: DDA Line Drawing Algorithm}
\begin{lstlisting}[language=C]
#include <stdio.h>
#include <math.h>
#include <graphics.h>
#include <conio.h>

#define BGI_PATH   "C:\\TURBOC3\\BGI"
#define LINE_COLOR WHITE

void drawLineDDA(float x1, float y1, float x2, float y2)
{
    float dx    = x2 - x1;
    float dy    = y2 - y1;
    float steps = (fabs(dx) > fabs(dy)) ? fabs(dx) : fabs(dy);
    if (steps == 0) {
        putpixel((int)(x1+0.5f),(int)(y1+0.5f), LINE_COLOR);
        return;
    }
    float xInc = dx / steps;
    float yInc = dy / steps;
    float x = x1, y = y1;
    int i;
    for (i = 0; i <= (int)steps; i++) {
        putpixel((int)(x+0.5f),(int)(y+0.5f), LINE_COLOR);
        x += xInc;
        y += yInc;
    }
}

int main(void)
{
    float x1, y1, x2, y2;
    printf("=== DDA Line Drawing Algorithm ===\n\n");
    printf("Enter starting point (x1 y1) : "); scanf("%f %f",&x1,&y1);
    printf("Enter ending   point (x2 y2) : "); scanf("%f %f",&x2,&y2);
    int gd=DETECT, gm;
    initgraph(&gd,&gm,BGI_PATH);
    drawLineDDA(x1,y1,x2,y2);
    getch(); closegraph();
    return 0;
}
\end{lstlisting}

\textbf{Experiment 1B: Bresenham's Line Drawing Algorithm}
\begin{lstlisting}[language=C]
#include <stdio.h>
#include <stdlib.h>
#include <graphics.h>
#include <conio.h>

#define BGI_PATH   "C:\\TURBOC3\\BGI"
#define LINE_COLOR WHITE
#define SIGN(v)  (((v)>0)-((v)<0))

void drawLineBresenham(int x1, int y1, int x2, int y2)
{
    int absDx=abs(x2-x1), absDy=abs(y2-y1);
    int xStep=SIGN(x2-x1), yStep=SIGN(y2-y1);
    int steep=(absDy>absDx), tmp, d, x=x1, y=y1, i;
    if (steep) {
        tmp=absDx; absDx=absDy; absDy=tmp;
        tmp=xStep; xStep=yStep; yStep=tmp;
    }
    d = 2*absDy - absDx;
    for (i=0; i<=absDx; i++) {
        steep ? putpixel(y,x,LINE_COLOR) : putpixel(x,y,LINE_COLOR);
        if (d>=0) { y+=yStep; d+=2*(absDy-absDx); }
        else        d+=2*absDy;
        x+=xStep;
    }
}

int main(void)
{
    int x1,y1,x2,y2;
    printf("=== Bresenham's Line Drawing Algorithm ===\n\n");
    printf("Enter starting point (x1 y1) : "); scanf("%d %d",&x1,&y1);
    printf("Enter ending   point (x2 y2) : "); scanf("%d %d",&x2,&y2);
    int gd=DETECT, gm;
    initgraph(&gd,&gm,BGI_PATH);
    drawLineBresenham(x1,y1,x2,y2);
    getch(); closegraph();
    return 0;
}
\end{lstlisting}

\section{Experiment 2: Midpoint Line Drawing Algorithm}

\subsection{Objective}
To implement the Midpoint Line Drawing Algorithm for rasterizing straight lines by evaluating an implicit line equation at the midpoint between candidate pixels.

\subsection{Theory/Background}
The Midpoint algorithm decides which of two candidate pixels to plot by evaluating the implicit line equation:
\begin{equation}
F(x, y) = dy \cdot x - dx \cdot y + dx \cdot y_1 - dy \cdot x_1
\end{equation}
at the midpoint between them. The decision parameter is scaled by 2 to avoid fractional arithmetic. Initial parameter: $d = 2 \cdot |dy| - |dx|$.

\subsection{Source Code}
\begin{lstlisting}[language=C]

#include <stdlib.h>
#include <graphics.h>
#include <conio.h>

#define SIGN(v)  (((v)>0)-((v)<0))

void drawLineMidpoint(int x1, int y1, int x2, int y2)
{
    int absDx=abs(x2-x1), absDy=abs(y2-y1);
    int xStep=SIGN(x2-x1), yStep=SIGN(y2-y1);
    int steep=(absDy>absDx), tmp, d, x=x1, y=y1, i;
    if (steep) {
        tmp=absDx; absDx=absDy; absDy=tmp;
        tmp=xStep; xStep=yStep; yStep=tmp;
    }
    d = 2*absDy - absDx;
    for (i=0; i<=absDx; i++) {
        steep ? putpixel(y,x,LINE_COLOR) : putpixel(x,y,LINE_COLOR);
        if (d>=0) { y+=yStep; d+=2*(absDy-absDx); }
        else        d+=2*absDy;

\section{Experiment 3: Midpoint Circle Drawing Algorithm}

\subsection{Objective}
To implement the Midpoint Circle algorithm utilizing 8-way symmetry to rasterize a complete circle.

\subsection{Theory/Background}
The Midpoint Circle algorithm exploits 8-way symmetry. Only one octant is computed; each point $(x,y)$ is reflected into all 8 octants. Starting at $(0, r)$, the initial decision parameter is $d = 1 - r$.

\subsection{Source Code}
\begin{lstlisting}[language=C]
#include <stdio.h>
#include <graphics.h>
#include <conio.h>

#define BGI_PATH    "C:\\TURBOC3\\BGI"
#define CIRCLE_COLOR WHITE

void plotSymmetricPoints(int xc, int yc, int x, int y)
{
    putpixel(xc+x, yc+y, CIRCLE_COLOR);
    putpixel(xc-x, yc+y, CIRCLE_COLOR);
    putpixel(xc+x, yc-y, CIRCLE_COLOR);
    putpixel(xc-x, yc-y, CIRCLE_COLOR);
    putpixel(xc+y, yc+x, CIRCLE_COLOR);
    putpixel(xc-y, yc+x, CIRCLE_COLOR);
    putpixel(xc+y, yc-x, CIRCLE_COLOR);
    putpixel(xc-y, yc-x, CIRCLE_COLOR);
}

void drawCircleMidpoint(int xc, int yc, int r)
{
    int x=0, y=r, d=1-r;
    plotSymmetricPoints(xc,yc,x,y);
    while (x < y) {
        x++;
        if (d<0) d += 2*x+1;
        else { y--; d += 2*x+1-2*y; }
        plotSymmetricPoints(xc,yc,x,y);
    }
}

int main(void)
{
    int xc,yc,r;
    printf("=== Midpoint Circle Drawing Algorithm ===\n\n");
    printf("Enter centre (xc yc) : "); scanf("%d %d",&xc,&yc);
    printf("Enter radius (> 0)   : "); scanf("%d",&r);
    int gd=DETECT, gm;
    initgraph(&gd,&gm,BGI_PATH);
    drawCircleMidpoint(xc,yc,r);
    getch(); closegraph();
    return 0;
}
\end{lstlisting}

\subsection{Output}
\begin{verbatim}

Enter centre (xc yc) : 300 300
Enter radius (> 0)   : 100

\section{Experiment 4: 2D Geometric Transformations}

\subsection{Objective}
To implement Translation, Rotation, and Scaling on user-defined polygons.

\subsection{Theory/Background}
\begin{itemize}
    \item \textbf{Translation:} $x' = x + tx$,\ $y' = y + ty$
    \item \textbf{Rotation (CCW from origin):}
    \begin{equation} x' = x\cos\theta - y\sin\theta,\quad y' = x\sin\theta + y\cos\theta \end{equation}
    \item \textbf{Scaling:} $x' = x \cdot sx$,\ $y' = y \cdot sy$
\end{itemize}

\subsection{Source Code}
\begin{lstlisting}[language=C]
#include <stdio.h>
#include <math.h>
#include <graphics.h>
#include <conio.h>

#define BGI_PATH     "C:\\TURBOC3\\BGI"
#define MAX_VERTICES  20
#define PI            3.14159265f

void drawShape(int x[], int y[], int n, int color) {
    int i; setcolor(color);
    for(i=0;i<n-1;i++) line(x[i],y[i],x[i+1],y[i+1]);
    line(x[n-1],y[n-1],x[0],y[0]);
}

void translate(int x[],int y[],int n,int tx,int ty,int xt[],int yt[]) {
    int i;
    for(i=0;i<n;i++){xt[i]=x[i]+tx; yt[i]=y[i]+ty;}
}

void rotate(int x[],int y[],int n,float ang,int xr[],int yr[]) {
    int i; float r=ang*PI/180.0f,c=(float)cos(r),s=(float)sin(r);
    for(i=0;i<n;i++){xr[i]=(int)(x[i]*c-y[i]*s); yr[i]=(int)(x[i]*s+y[i]*c);}
}

void scaleShape(int x[],int y[],int n,float sx,float sy,int xs[],int ys[]) {
    int i;
    for(i=0;i<n;i++){xs[i]=(int)(x[i]*sx); ys[i]=(int)(y[i]*sy);}
}

int main(void)
{
    int x[MAX_VERTICES],y[MAX_VERTICES];
    int xt[MAX_VERTICES],yt[MAX_VERTICES];
    int xr[MAX_VERTICES],yr[MAX_VERTICES];
    int xs[MAX_VERTICES],ys[MAX_VERTICES];
    int n,tx,ty,i; float angle,sx,sy;

    printf("Enter number of vertices (3-%d): ",MAX_VERTICES); scanf("%d",&n);
    for(i=0;i<n;i++){printf("  Vertex %d (x y): ",i+1); scanf("%d %d",&x[i],&y[i]);}
    printf("Translation (tx ty): ");  scanf("%d %d",&tx,&ty);
    printf("Rotation angle (deg): "); scanf("%f",&angle);
    printf("Scale (sx sy): ");        scanf("%f %f",&sx,&sy);

    int gd=DETECT,gm; initgraph(&gd,&gm,BGI_PATH);
    drawShape(x,y,n,WHITE);
    translate(x,y,n,tx,ty,xt,yt);  drawShape(xt,yt,n,GREEN);
    rotate(x,y,n,angle,xr,yr);     drawShape(xr,yr,n,RED);
    scaleShape(x,y,n,sx,sy,xs,ys); drawShape(xs,ys,n,YELLOW);
    getch(); closegraph(); return 0;
}
\end{lstlisting}

\section{Experiment 5: Shearing Transformation}

\subsection{Objective}
To implement X-axis and Y-axis shearing transformations on a 2D polygon.

\subsection{Theory/Background}
\begin{itemize}
    \item \textbf{X-axis Shear:} $x' = x + shx \cdot y$,\ $y' = y$
    \item \textbf{Y-axis Shear:} $x' = x$,\ $y' = y + shy \cdot x$
\end{itemize}

\subsection{Source Code}
\begin{lstlisting}[language=C]

\section{Experiment 6: Flood Fill Algorithm (4-Connected \& 8-Connected)}

\subsection{Objective}
To implement an iterative Flood Fill algorithm using 4-connected and 8-connected logic, avoiding recursion to prevent stack overflow.

\subsection{Theory/Background}
Flood fill replaces all pixels of \texttt{oldColor} connected to a seed with \texttt{newColor}.
\begin{itemize}
    \item \textbf{8-Connected:} Explores all 8 surrounding pixels (cardinal + diagonal).
    \item \textbf{4-Connected:} Explores only 4 cardinal neighbors (N, S, E, W).
\end{itemize}
An explicit LIFO stack replaces recursion to avoid Turbo C stack overflow.

\subsection{Source Code}
\textbf{Experiment 6A: 8-Connected Flood Fill}
\begin{lstlisting}[language=C]
#include <stdio.h>
#include <graphics.h>
#include <conio.h>

#define BGI_PATH    "C:\\TURBOC3\\BGI"
#define SCREEN_W 640
#define SCREEN_H 480
#define RECT_X1 100
#define RECT_Y1 100
#define RECT_X2 200
#define RECT_Y2 200
#define STACK_SIZE 12000

static int stackX[STACK_SIZE], stackY[STACK_SIZE], stackTop;
static int dx8[]={1,-1,0,0,1,-1,1,-1};
static int dy8[]={0,0,1,-1,1,-1,-1,1};

void floodFill8(int sx,int sy,int old,int nw){
    int x,y,nx,ny,i;
    if(old==nw||getpixel(sx,sy)!=old) return;
    putpixel(sx,sy,nw); stackTop=0;
    stackX[stackTop]=sx; stackY[stackTop]=sy; stackTop++;
    while(stackTop>0){
        stackTop--; x=stackX[stackTop]; y=stackY[stackTop];
        for(i=0;i<8;i++){
            nx=x+dx8[i]; ny=y+dy8[i];
            if(nx<0||nx>=SCREEN_W||ny<0||ny>=SCREEN_H) continue;
            if(getpixel(nx,ny)==old){
                putpixel(nx,ny,nw);
                if(stackTop<STACK_SIZE){stackX[stackTop]=nx;stackY[stackTop]=ny;stackTop++;}
            }
        }
    }
}

int main(void){
    int sx,sy,fc,old;
    printf("=== Flood Fill (8-Connected) ===\n");
    printf("Seed (x y): "); scanf("%d %d",&sx,&sy);
    printf("Fill colour (0-15): "); scanf("%d",&fc);
    int gd=DETECT,gm; initgraph(&gd,&gm,BGI_PATH);
    setcolor(WHITE); rectangle(RECT_X1,RECT_Y1,RECT_X2,RECT_Y2);
    old=getpixel(sx,sy); floodFill8(sx,sy,old,fc);
    getch(); closegraph(); return 0;
}
\end{lstlisting}

static int stackX[STACK_SIZE], stackY[STACK_SIZE], stackTop;
static int dx4[]={1,-1,0,0};
static int dy4[]={0,0,1,-1};

void floodFill4(int sx,int sy,int old,int nw){
    int x,y,nx,ny,i;
    if(old==nw||getpixel(sx,sy)!=old) return;
    putpixel(sx,sy,nw); stackTop=0;
    stackX[stackTop]=sx; stackY[stackTop]=sy; stackTop++;
    while(stackTop>0){
        stackTop--; x=stackX[stackTop]; y=stackY[stackTop];
        for(i=0;i<4;i++){
            nx=x+dx4[i]; ny=y+dy4[i];
            if(nx<0||nx>=SCREEN_W||ny<0||ny>=SCREEN_H) continue;
            if(getpixel(nx,ny)==old){
                putpixel(nx,ny,nw);
                if(stackTop<STACK_SIZE){stackX[stackTop]=nx;stackY[stackTop]=ny;stackTop++;}
            }
        }
    }
}

int main(void){
    int sx,sy,fc,old;
    printf("=== Flood Fill (4-Connected) ===\n");
    printf("Seed (x y): "); scanf("%d %d",&sx,&sy);

    int gd=DETECT,gm; initgraph(&gd,&gm,BGI_PATH);
    setcolor(WHITE); rectangle(RECT_X1,RECT_Y1,RECT_X2,RECT_Y2);
    old=getpixel(sx,sy); floodFill4(sx,sy,old,fc);
    getch(); closegraph(); return 0;
}

\section{Experiment 7: Boundary Fill Algorithm (8-Connected \& 4-Connected)}

\subsection{Objective}

\subsection{Theory/Background}

\section{Experiment 8: Cubic B\'{e}zier Curve}

\subsection{Objective}
To implement and rasterize a Cubic B\'{e}zier Curve using control point parametric equations.

\subsection{Theory/Background}
A cubic B\'{e}zier curve is defined by four control points $P_0, P_1, P_2, P_3$ and parameter $t \in [0,1]$:
\begin{equation}
B(t) = (1-t)^3 P_0 + 3(1-t)^2 t\, P_1 + 3(1-t)t^2 P_2 + t^3 P_3
\end{equation}
$P_0$ and $P_3$ are the endpoints; $P_1$ and $P_2$ are control handles.

\subsection{Source Code}
\begin{lstlisting}[language=C]
#include <stdio.h>
#include <graphics.h>
#include <conio.h>

#define BGI_PATH      "C:\\TURBOC3\\BGI"
#define BEZIER_STEPS  1000

void drawBezier(int x0,int y0,int x1,int y1,int x2,int y2,int x3,int y3)
{
    int i,px,py;
    float t,u,u2,u3,t2,t3;
    setcolor(CYAN);
    for(i=0;i<=BEZIER_STEPS;i++){
        t=(float)i/BEZIER_STEPS; u=1.0f-t;
        u2=u*u; u3=u2*u; t2=t*t; t3=t2*t;
        px=(int)(u3*x0+3*u2*t*x1+3*u*t2*x2+t3*x3);
        py=(int)(u3*y0+3*u2*t*y1+3*u*t2*y2+t3*y3);
        if(px<0||px>=getmaxx()||py<0||py>=getmaxy()) continue;
        putpixel(px,py,CYAN);
    }
}

int main(void)
{
    int x0,y0,x1,y1,x2,y2,x3,y3;
    printf("=== Cubic Bezier Curve ===\n\n");
    printf("P0 (x y): "); scanf("%d %d",&x0,&y0);
    printf("P1 (x y): "); scanf("%d %d",&x1,&y1);
    printf("P2 (x y): "); scanf("%d %d",&x2,&y2);
    printf("P3 (x y): "); scanf("%d %d",&x3,&y3);
    int gd=DETECT,gm; initgraph(&gd,&gm,BGI_PATH);
    drawBezier(x0,y0,x1,y1,x2,y2,x3,y3);
    setcolor(DARKGRAY);
    line(x0,y0,x1,y1); line(x1,y1,x2,y2); line(x2,y2,x3,y3);
    setcolor(GREEN);  circle(x0,y0,3); circle(x3,y3,3);
    setcolor(YELLOW); circle(x1,y1,3); circle(x2,y2,3);
    getch(); closegraph(); return 0;
}
\end{lstlisting}

\subsection{Output}
% Save your screenshot as exp8_bezier.png
\begin{figure}[h!]
    \centering
    \includegraphics[width=0.65\textwidth]{exp8_bezier.png}
    \caption{Output for Cubic B\'{e}zier Curve (Cyan=Curve, Green=Endpoints, Yellow=Handles, Gray=Control Polygon)}
\end{figure}

\subsection{Discussion}
The curve renders anchored to $P_0$ and $P_3$, curving towards $P_1$ and $P_2$. Using 1000 steps produces a smooth arc.

\subsection{Conclusion}
Parametric polynomial evaluation over fractional $t$-increments handles curve geometry precisely, forming a foundation for vector graphics.

\section{Experiment 9: Animation --- Man Walking on a Rainy Day}

\subsection{Objective}
To create a looping animation combining static backgrounds, translating components, and phase-switched character animation via double-buffered page flipping.

\subsection{Theory/Background}
Double-buffered page flipping (\texttt{setactivepage}/\texttt{setvisualpage}) eliminates flicker. Rain streaks cycle downward each frame; the stick-figure man traverses left with a 2-phase leg cycle, wrapping at the screen edge.

\subsection{Source Code}
\begin{lstlisting}[language=C]
#include <graphics.h>
#include <conio.h>
#include <dos.h>

#define BGI_PATH        "C:\\TURBOC3\\BGI"
#define SCREEN_W 640
#define SCREEN_H 480
#define GROUND_Y 400
#define MAN_START_X 620
#define MAN_Y       342
#define MAN_STEP      2
#define MAN_WRAP_EXIT  -60
#define MAN_WRAP_ENTRY 660
#define RAIN_ROW_GAP  18
#define RAIN_COL_GAP  25
#define RAIN_SPEED     3
#define FRAME_DELAY   35
#define LEG_FRAMES     8

void drawBackground(void){
    setfillstyle(SOLID_FILL,BLACK); bar(0,0,SCREEN_W-1,GROUND_Y-1);
    setcolor(WHITE); setfillstyle(SOLID_FILL,WHITE); fillellipse(580,55,28,28);
    setcolor(DARKGRAY); setfillstyle(SOLID_FILL,DARKGRAY);
    fillellipse(80,85,38,20); fillellipse(118,72,48,26); fillellipse(158,85,38,20);
    fillellipse(300,65,42,22); fillellipse(342,52,52,28); fillellipse(384,65,42,22);
    fillellipse(530,58,38,20); fillellipse(566,46,48,26); fillellipse(606,58,38,20);
    setfillstyle(SOLID_FILL,DARKGRAY); bar(0,GROUND_Y,SCREEN_W-1,SCREEN_H-1);
    setcolor(LIGHTGRAY);
    line(0,GROUND_Y,SCREEN_W-1,GROUND_Y); line(0,SCREEN_H-2,SCREEN_W-1,SCREEN_H-2);
    setcolor(WHITE); line(0,440,SCREEN_W-1,440);
}

void drawRain(int off){
    int col,row,rx,ry; setcolor(LIGHTBLUE);
    for(row=0;row<GROUND_Y;row+=RAIN_ROW_GAP)
        for(col=0;col<SCREEN_W+RAIN_COL_GAP;col+=RAIN_COL_GAP){
            rx=col-(off%RAIN_COL_GAP); ry=(row+off)%GROUND_Y;
            line(rx,ry,rx-4,ry+12);
        }
}

void drawMan(int mx,int my,int lp){
    setcolor(BROWN); line(mx-14,my+18,mx-14,my-22);
    setcolor(RED); setfillstyle(SOLID_FILL,RED); fillellipse(mx-14,my-22,28,10);
    setcolor(DARKGRAY); arc(mx-14,my-22,0,180,28); line(mx-42,my-22,mx+14,my-22);
    setcolor(WHITE); circle(mx,my-14,10); line(mx,my-4,mx,my+30);
    line(mx,my+8,mx-14,my+18);
    lp==0 ? line(mx,my+8,mx+16,my+22) : line(mx,my+8,mx+10,my+26);
    if(lp==0){line(mx,my+30,mx-14,my+58); line(mx,my+30,mx+10,my+58);}
    else     {line(mx,my+30,mx-8, my+58); line(mx,my+30,mx+14,my+58);}
}

int main(void){
    int manX=MAN_START_X,rainOff=0,lp=0,frame=0,page=0;
    int gd=DETECT,gm; initgraph(&gd,&gm,BGI_PATH);
    while(!kbhit()){
        page=1-page; setactivepage(page); cleardevice();
        drawBackground(); drawRain(rainOff); drawMan(manX,MAN_Y,lp);
        setvisualpage(page);
        manX-=MAN_STEP;
        rainOff=(rainOff+RAIN_SPEED)%(RAIN_ROW_GAP*RAIN_COL_GAP);
        frame=(frame+1)%(LEG_FRAMES*2);
        if(frame%LEG_FRAMES==0) lp=1-lp;
        if(manX<MAN_WRAP_EXIT) manX=MAN_WRAP_ENTRY;
        delay(FRAME_DELAY);
    }
    getch(); closegraph(); return 0;
}
\end{lstlisting}

Page flipping ensures no partial frames are ever displayed. Rain and leg-phase state variables advance each frame for smooth animation.

\subsection{Conclusion}
Double-buffering combined with state variable logic produces flicker-free animations in C BGI graphics pipelines.
